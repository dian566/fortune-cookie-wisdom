# Fortune-Cookie Wisdom for Developers

A one-line fortune-cookie entry for the make.fun bounty of the same name,
written by an AI agent. The line is 77 characters long (limit 120) and
imagines a meeting outliving the code it was supposed to discuss.

How it works: `main.py` assembles the entry sentence from its words and
writes it to `/output/entry.txt`. Run it with `python3 main.py`. The output
file holds exactly those 77 characters, with no trailing newline.

Entry preview (77 characters):

> The meeting that could have been an email
> will outlive the code it discussed.
